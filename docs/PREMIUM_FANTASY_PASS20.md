## Performance contract
No autoplay video, embedded player or WebGL canvas is added to Home or the game portal. Hero dimensions are reserved. Below-fold art is lazy-loaded and sections defer offscreen rendering. Phone layouts retain the Pass 19 static Veyr profile. Existing small public image assets are reused; no new runtime dependency is required.

## Public-information boundary
Do not import game documentation, definitive characters, private lore, production models, rigs, master textures, quest data or unpublished map information into this surface. Do not turn promotional illustration into an asserted gameplay screenshot. Public progress uses honest general states, not invented percentages or dates.

Official destinations: www.xethkioz.com.ar, Threads, Instagram, TikTok and YouTube. The website and Threads are prioritized. Retired personal streaming destinations must not be reintroduced.
