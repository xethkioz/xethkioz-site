# WORLD OF XETHKIOZ — Imported open terrain sources

These files are imported only as generic terrain/environment source material. WORLD OF XETHKIOZ does not reuse Tuxemon names, creatures, characters, logos or narrative identity.

## Source repository
- Project: Tuxemon
- Repository: https://github.com/Tuxemon/Tuxemon
- Upstream branch used by importer: `development`

## Production rule
1. No Pokémon-identifiable asset is permitted in the production branch.
2. No Tuxemon creature, character, logo, faction or proper noun is permitted in WORLD OF XETHKIOZ.
3. Generic environment art may be recolored, recomposed and combined with original Xethkioz assets.
4. Any future third-party asset must be added to a provenance file before it enters a release build.
5. The final Steam credits/licensing screen will include all required notices even when attribution is not legally required for a CC0 source.

## Evidence
The Tuxemon `ATTRIBUTIONS.md` states these three selected assets as Public Domain / CC0. This restricted list is deliberate; it avoids treating the entire upstream graphics folder as if it had one uniform license.
