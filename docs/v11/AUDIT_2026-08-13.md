## Seguridad Supabase

Hallazgos del advisor:

1. `get_huellas_stats()` es `SECURITY DEFINER` y actualmente puede ejecutarse mediante roles públicos.
2. `register_huellas_visit()` es `SECURITY DEFINER`, puede ejecutarse públicamente y modifica el contador de visitas.
3. `huellas_stats` tiene RLS sin políticas, mientras el acceso se realiza mediante RPC SECURITY DEFINER.
4. Leaked Password Protection de Supabase Auth está desactivado.
5. El advisor marca varios índices como `unused`; no se eliminarán únicamente por esa métrica.

El JavaScript público de Huellas llama directamente a los RPC de estadísticas con la publishable key. El bloqueo por `sessionStorage` sólo limita al navegador cooperativo y no protege la integridad del contador frente a llamadas directas.

## Coherencia de rutas / SEO

### Huellas / Fun

- La Home presenta `HUELLAS DE PUAN` pero su destino histórico es `/fun`.
- El runtime de `/fun` redirige normalmente a `/mascotas/`.
- El shell SEO de `/fun`, sin embargo, declara `Chaos Alley`, memes y humor gamer.

Resultado: humano y crawler reciben identidades conceptualmente diferentes.

### Nexus City

- `NexusCity.tsx` ya es una experiencia completa.
- `/nexus-city` está redirigido a `/fun#nexus-city` en `vercel.json` y también en React.
- El HTML inicial de `/nexus-city` hereda actualmente el shell SEO de `/fun` / Chaos Alley.

Resultado: Nexus City existe funcionalmente, pero no posee identidad de URL/SEO propia.

### Green Node

- `/green-node` devuelve el shell HTML genérico del Home.
- Tiene `X-Robots-Tag: noindex, nofollow, noarchive`.
- `robots.txt` también lo bloquea.
- No existe shell SEO específico de Green Node.

Decisión v11: mantener el Vault privado/noindex, pero crear una capa útil pública PROTECT/RADAR/LAB antes de indexar Green Node.

### Huellas estático

- `/mascotas/` funciona como sitio estático propio.
- Falta un contrato SEO equivalente a los portales principales: canonical, Open Graph y sitemap dedicado.
- La atribución de portada todavía menciona Wikimedia aunque la portada servida actualmente es un SVG local; debe verificarse y corregirse.

## Sitemap

El sitemap aún expone `/fun` como portal localizado ES/EN y no presenta `/mascotas/` ni `/nexus-city` como destinos principales propios. También indexa publicaciones legacy `fun-*` sin fuentes.

## Higiene de repositorio

Existen PRs abiertas de un producto Windows/Python (`Factura Salud`) dentro del repo web. No rompen producción, pero v11 debe separar productos independientes en repositorios independientes y cerrar PRs obsoletas después de confirmar su traslado/estado.
