# WORLD OF XETHKIOZ — Canon de expansiones v3.4

**Fecha:** 2026-09-08
**Estado:** CANON / REGLA DE PRODUCCIÓN

## Estructura oficial del producto

### Juego base — IZRDRALAR
Izrdralar constituye el juego base completo de **WORLD OF XETHKIOZ**.

Todo el lanzamiento inicial, la campaña base, progresión principal, sistemas fundamentales, Golden Region, demo de Steam y contenido de salida deben producirse alrededor de Izrdralar.

El juego base debe sentirse completo por sí mismo y no depender de comprar futuras expansiones para cerrar su arco principal.

### Primera expansión — DESFRALAR
Desfralar queda reservado como la **primera expansión oficial** posterior al lanzamiento del juego base.

Debe ampliar sistemas y progresión sin ser necesario para completar la campaña principal de Izrdralar.

### Segunda expansión — XIOMALAR
Xiomalar queda reservado como la **segunda expansión oficial**.

Su escala, tono y progresión deberán sentirse como una evolución posterior a Desfralar, vinculada a regiones superiores, entidades antiguas y poderes de mayor escala.

### Posible tercera expansión — ZODNIGHT
**Zodnight** queda registrado como nombre y concepto de trabajo para una **posible tercera expansión**.

No se define todavía su lore, mapa, sistemas ni posición narrativa exacta. No debe consumir recursos de producción del juego base ni de las dos primeras expansiones hasta que el proyecto lo justifique.

## Regla de scope

1. Producción actual: **Izrdralar**.
2. Desfralar y Xiomalar pueden diseñarse a nivel de lore/semillas narrativas, pero no deben expandir el scope de la demo ni del lanzamiento base.
3. Zodnight permanece como reserva futura.
4. Sistemas del juego base deben diseñarse para poder escalar a expansiones sin requerir reescrituras estructurales.
5. La campaña base debe tener cierre propio y dejar ganchos opcionales hacia Desfralar.

## Orden comercial y narrativo

**WORLD OF XETHKIOZ — Juego Base: IZRDRALAR**
→ **Expansión I: DESFRALAR**
→ **Expansión II: XIOMALAR**
→ **Expansión III posible: ZODNIGHT**

Esta decisión prevalece sobre cualquier documento anterior que tratara Desfralar o Xiomalar como territorios incluidos dentro del lanzamiento base.
