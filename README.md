# XETHKIOZ: Wildbound

Original 2D survival/platform-adventure prototype built with Godot 4.7.2.

## Prototype features
- 32-map campaign.
- Bosses on 5, 10, 15, 20, 25, 30 and final encounter on 32.
- Increasing boss phases and mechanics.
- Fast run, jump, dash and melee combat.
- Survival supplies meter.
- Weapon, armor and charm progression.
- Eight collectible Wildling companions.
- Companion passive attacks and active skill.
- Persistent JSON save.
- Procedural prototype stages and fully original placeholder visuals.
- Windows x86_64 export preset.

## Controls
A/D or arrows: move. Space/W: jump. Shift: dash. J/X: attack. K/C: companion skill.

This prototype takes broad inspiration from classic 16-bit platforming pacing and creature-collection progression, but contains no copied characters, sprites, maps, music or other copyrighted game assets.
